# 订单簿小数价格档位展示设计

> 适用项目：`RIVERS0FT/Economy`
> 状态：统一资产订单簿客户端展示防回退规则
> 依赖权威：`UNIFIED_ASSET_ORDER_BOOK_DESIGN.md`

## 1. 价格有效性

商品与工厂订单价格统一使用 `0.01` 最小价格步长。客户端订单簿、默认价格、未完成订单和本地成交展示必须复用同一价格校验：

```text
价格为有限数值
且价格 >= 0.01
且价格最多两位小数
```

订单簿展示层不得使用 `Number.isInteger(price)`、`price >= 1` 或整数解析过滤玩家、人口、市场储备订单。

## 2. 档位聚合

只有 `open` 或 `partial`、`remaining > 0` 且价格有效的订单进入档位。相同方向与相同价格按当前 `remaining` 聚合，保留独立订单笔数；买盘按价格降序，卖盘按价格升序，聚合后再截取最优五档。

`0.01`、`1.10`、`1.23` 与整数价格必须按各自真实价格显示和聚合。三位及更多小数、非有限值、零价和负价不得进入档位。

## 3. 格式与边界

价格继续通过统一货币格式显示两位小数。展示修复不得修改服务器订单、撮合价格、maker price、冻结资金、手续费、成交历史或估值；只修正客户端档位筛选。

## 4. 防回退验证

`scripts/verify-order-book-decimal-levels.mjs` 必须覆盖：

- `0.01` 最低合法价格；
- 两位小数买卖单显示；
- 同价小数订单合并；
- 买卖盘排序；
- 三位小数、零价、非有限值、已完成订单和零剩余订单过滤；
- 源码不再包含整数专属价格筛选。
