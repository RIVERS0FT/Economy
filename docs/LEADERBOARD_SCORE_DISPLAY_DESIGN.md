# Economy 排行榜成绩显示设计

> 状态：排行榜成绩显示补充基线
> 适用项目：`RIVERS0FT/Economy`
> 更新时间：2026-07-28
> 客户端状态版本：21
> 世界状态版本：18

本文件只补充排行榜成绩值的显示规则；排行榜业务口径、周期、奖励和排序继续以 `PRODUCT_AND_GAMEPLAY_DESIGN.md` 为准，页面归属与结构继续以 `PAGE_CONTENT_AND_NAVIGATION_DESIGN.md` 为准。

## 生产榜数量

生产榜的 `quantity` 成绩只显示经过 `formatNumber` 千分位格式化后的纯数字，例如：

```text
1,234
```

不得在数字后附加“个”“件”“单位”或其他数量单位，也不得恢复“分”。该规则同时适用于榜单前十名和“我的成绩”。

财富榜、增长榜和交易榜的普通货币格式保持不变；排行榜成绩显示不得改变服务器成绩、排序、同分规则、奖励或历史结算。

## 防回退

不得：

- 把生产榜数量恢复为 `1,234 个`、`1,234 件`、`1,234 单位` 或 `1,234 分`；
- 只修改榜单行而遗漏“我的成绩”，或只修改“我的成绩”而遗漏榜单行；
- 为去掉单位而绕过共享 `scoreValue`，建立两套生产榜格式化逻辑；
- 因显示调整修改服务器 `quantity` 值、生产规则版本、排行榜排序或奖励。
