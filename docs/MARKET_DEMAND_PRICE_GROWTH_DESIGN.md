# 人口买单价格增长设计

> 状态：市场需求模型 10 的成交不足追价规则
> 适用项目：`RIVERS0FT/Economy`
> 生效日期：2026-07-25
> 优先级：本文件对人口直接需求买单的成交不足追价参数具有专项权威性；其他设计文档中的旧参数或旧人口需求描述与本文件冲突时，以本文件、`docs/PRODUCT_AND_GAMEPLAY_DESIGN.md` 和当前模型 10 代码为准。

## 1. 调整目标

降低人口直接需求在零成交、部分成交不足和高压力短缺状态下的价格增长速度，避免连续几个五分钟周期快速抬升人口最高买价。

本次调整只改变直接需求报价锚点的上涨速度，不改变人口真实钱包、周期预算、预算分配、三档需求曲线、动态参考价、派生流动性、持续过剩降价或订单价值上限。

## 2. 权威参数

- 零成交最低涨幅：0.75%
- 参考价缺口恢复：5%
- 单周期参考价恢复上限：2%
- 部分成交不足恢复：2.5%
- 高压力追涨上限：0.5%

对应代码常量：

```js
DIRECT_DEMAND_UNFILLED_PRICE_STEP = 1.0075
DIRECT_DEMAND_UNFILLED_REFERENCE_GAP_RATE = 0.05
DIRECT_DEMAND_UNFILLED_REFERENCE_MAX_RATE = 0.02
DIRECT_DEMAND_BELOW_REFERENCE_RECOVERY_RATE = 0.025
DIRECT_DEMAND_SHORTAGE_PRICE_STEP = 1.005
```

## 3. 零成交规则

上一完整周期存在直接需求且直接成交数量为 0 时：

```text
参考价缺口 = max(0, 参考价 - 旧锚点)

上涨量 = max(
  旧锚点 × 0.75%,
  min(
    参考价缺口 × 5%,
    参考价 × 2%
  )
)

新锚点 = 旧锚点 + 上涨量
```

零成交不得直接把报价锚点跳到参考价，也不得使用最近成交价替代报价锚点。

## 4. 部分成交不足规则

上一完整周期存在直接成交，但直接成交率低于需求组目标满足率时：

```text
当旧锚点 < 参考价：
新锚点 = 旧锚点 + (参考价 - 旧锚点) × 2.5%

当旧锚点 >= 参考价：
新锚点 = 旧锚点
```

食品市场目标满足率继续为 82%，社会消费市场目标满足率继续为 78%。

## 5. 高压力追涨规则

商品压力达到 1.15 时，参考价的 103% 继续作为短缺目标，但直接需求曲线基准每个需求周期最多在当前报价锚点上追涨 0.5%：

```text
曲线基准 = min(
  max(报价锚点, 参考价 × 103%),
  报价锚点 × 100.5%
)
```

三档直接需求价格必须继续基于同一个曲线基准，禁止价格倒挂。

## 6. 保持不变

- 需求周期继续为五分钟；
- 预算继续按 50%／30%／20% 拆成 100%／97%／93% 三档买盘；
- 报价锚点合法范围继续为绝对价格 1 至商品基础价的 300%；
- 普通达标或无直接需求时继续按 30% 差额向参考价双向回归；
- 连续两个周期达到直接成交率至少 95% 且直接成交延迟得分至少 85% 后，继续从第二个周期起每周期乘 98% 降价；
- 派生流动性继续使用参考价，不读取直接需求报价锚点；
- 人口周期预算、真实冻结资金、旧订单保留比例和订单价值上限保持不变；
- 本次不修改市场需求模型版本，因为没有状态结构、迁移或订单字段变化。

## 7. 回归要求

自动化验证必须覆盖：

1. 连续零成交时未取整报价锚点按 0.75% 最低步长累计；
2. 锚点低于参考价且零成交时，缺口恢复为 5% 且单周期不超过参考价的 2%；
3. 部分成交不足时只恢复参考价缺口的 2.5%；
4. 高压力状态每周期最多追涨 0.5%；
5. 持续过剩降价、绝对下限 1、三档曲线和派生流动性规则保持不变；
6. 价格变化不得增加人口预算或发行额外普通货币。
