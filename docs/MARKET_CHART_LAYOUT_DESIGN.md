# Economy 市场行情图布局设计

> 状态：市场行情图几何、交互与可读性唯一专项基线
> 适用项目：`RIVERS0FT/Economy`
> 更新时间：2026-08-02
> 上位文档：`PAGE_CONTENT_AND_NAVIGATION_DESIGN.md`、`UI_DESIGN_SYSTEM.md`

## 1. 规则优先级

本文件只负责市场页近 24h 行情图的绘图区、坐标、悬浮交互、图例与安全区几何。与通用页面文档发生冲突时，本文件的行情图专项规则优先。

`PAGE_CONTENT_AND_NAVIGATION_DESIGN.md` 中“窄屏优先压缩成交量绘图区”“完整行情图固定使用 16:9”“移动端必须保留可见‘时间’横轴标题”的旧表述已被本文件废止。`16:9` 只允许作为桌面基础比例与首次渲染回退，不得作为窄屏最终强制比例。旧版“价格区与成交量区必须保持正间距”的规则同样废止，当前使用零间距连续双 Grid。

## 2. ECharts 唯一实现

- 市场行情图必须使用共享 `EconomyChart` 和 Apache ECharts 的 **ECharts SVG** 渲染，不得恢复手写 `<svg>`、`polyline`、`polygon` 或成交量 `rect`。
- 图表固定使用价格区和成交量区两个纵向 **双 Grid**；价格 `line` 与成交量 `bar` 共享同一 24h 时间尺度。
- 两个 Grid 必须零间距连续排列，并在共同边界绘制稳定 `1px` 分界线；不得重新使用空白间距把它们拆成两个独立图表。
- ECharts 只负责渲染。24h 聚合、整数坐标、颜色方向、动态刻度和几何结果仍由项目纯函数计算，业务规则不得交给库默认值猜测。
- 业务页面不得直接调用 `echarts.init`；初始化、`ResizeObserver`、逐帧合并 resize、Option 更新和 `dispose()` 统一由 `EconomyChart` 负责。
- 市场组件必须在外层提供稳定 `data-*` 几何、刻度与交互接口；浏览器回归不得依赖 ECharts 私有 SVG 类名或内部 DOM 层级。
- 移动端触控高亮必须按通用触摸规则统一关闭：共享 `.economy-chart` 根节点、`.economy-chart__canvas`、ECharts 动态生成的 SVG／Canvas 子节点，以及直接绑定 Pointer Event 的 `.market-history-chart` 外层都必须计算为透明 `-webkit-tap-highlight-color`。实现唯一放在 `src/styles/mobile-interaction.css`，不得通过禁用 Pointer Event、Tooltip 或键盘 `:focus-visible` 规避蓝色区域。

## 3. 数据与动态坐标基线

- 行情仍统计当前资产最近 24h，使用 `6m × 240` 固定数据分段；动态变化只影响可见刻度密度，不改变聚合窗口或经济数据。
- 价格折线位于上方，成交量柱状图位于下方；两个 x 轴必须使用同一动态时间间隔并保持网格线对齐。
- 横轴时间间隔必须根据真实绘图区宽度、根字号和 compact／full 变体，从 `1／2／3／4／6／8／12` 小时中选择，宽屏显示更多刻度，窄屏或放大字号自动减少刻度。
- 价格与成交量纵轴的目标刻度数必须按各自真实像素高度和根字号动态计算；价格轴仍只能显示整数刻度，步长使用 `1／2／5 × 10^n`。
- 价格纵轴必须从所有合法整数候选中选择额外空白最少的区间，再以目标刻度数作为次级排序；不得为了凑固定刻度数把约 `3～6` 的真实数据扩展成 `0～10`。只有真实最低价接近零或完整覆盖数据确有需要时才能包含零点；恒定价格必须围绕当前整数价格保留对称或近似对称的最小可读区间。
- 价格折线固定使用信息色 `--color-info`，与净主动买入的成功色 `--color-success`、净主动卖出的危险色和方向未知的中性色保持不同视觉语义；价格面积填充必须复用信息色并降低不透明度，不得再用成功色冒充价格色。
- 零间距双 Grid 的共享边界只能显示一项纵轴刻度标签：价格轴保留最小刻度，成交量轴隐藏最大刻度。完整行情图的成交量轴目标刻度不得低于 3 个，因此隐藏最大刻度后仍必须至少显示 `0` 和一个非零中间刻度；compact 变体允许最低 2 个刻度。
- 成交量轴继续使用 K／M／B／T 紧凑格式；两个纵轴都不受设置页“紧凑数字”开关影响。
- 图例只显示“净主动买入”和“净主动卖出”；中性成交量继续使用灰色柱，但不显示“均衡／方向未知”图例。
- 横纵轴刻度、桌面轴标题、移动分区标题和图例文字使用 `--color-text-secondary`，不得继续以过低对比度的 muted 文本承担主要读数。

## 4. 统一悬浮交互

- 价格与成交量不得分别处理悬浮。两个 x 轴必须通过 `axisPointer.link` 联动，鼠标位于任一 Grid 时都指向同一个 6 分钟分段。
- 竖向指针必须在零间距双 Grid 中保持同一 x 坐标、样式和虚线节奏，视觉上从价格区连续贯穿成交量区。
- 全图只显示一个 Tooltip；其数据索引必须由统一 `axisValue` 映射到分段，不得依赖当前触发 Series 的 `dataIndex`。
- Tooltip 只展示当前分段的时间、价格、总成交量、主动买入、主动卖出、方向未知和净主动量，不得显示玩家身份、订单来源或交易对手。
- AxisPointer 必须关闭自动 Series emphasis，价格线和成交量柱也必须禁用 hover emphasis；悬浮前后价格折线的颜色、宽度与不透明度必须保持不变，不得隐藏或被面积层覆盖。
- 价格折线必须保持高于自身面积填充的稳定渲染层级。
- 当指针仍位于行情数据区时，普通 `5s` 状态轮询、无关 React 重渲染和尺寸未变化的页面更新不得清除当前 Tooltip 或 AxisPointer。
- 真实行情数据或 6 分钟窗口变化需要更新 ECharts Option 时，必须在 Option 应用后恢复鼠标当前横向位置对应的分段 Tooltip；不得要求用户再次移动鼠标。
- Tooltip 只允许在指针离开行情数据区、资产切换、页面卸载或用户主动关闭时隐藏。不得使用 `alwaysShowContent`、超长 `hideDelay` 或禁止正常离开隐藏来掩盖更新重置问题。

## 5. 成交量绘图区可读性

完整行情图的成交量绘图区必须保持最低可读屏幕高度，不得作为底部标注空间不足时的压缩对象。

- full 变体任意支持断点下成交量绘图区实际屏幕高度不得低于 `68px`，并随根字号放大；compact 变体最低仍为 `48px`。
- 成交量绘图区不得低于价格区与成交量区合计数据绘图区的 `22%`；零间距分界线不计入数据区高度。
- full 变体成交量纵轴至少生成 3 个刻度，隐藏共享边界最大刻度后仍须保留一个非零可见刻度；刻度不得互相覆盖。
- 所有非零成交柱必须设置最小可见高度 `2px`，同时继续使用线性纵轴和真实数值比例；不得通过对数轴、平方根轴或修改成交量数据放大小成交。
- 成交量柱必须完整位于成交量绘图区内。
- 价格区底边与成交量区顶边必须使用同一坐标；视觉分区仅由 `1px` 分界线完成。
- 共同边界的标签所有权固定属于价格轴。成交量最大值仍可通过 Tooltip 和其余动态刻度判断，不得在边界重复显示。

成交量高度必须取以下三项的最大值：桌面首选高度、满足 full／compact 最低高度和字号间距所需高度、满足 `22%` 数据区占比所需高度。

## 6. 动态总高度与轴标题

图表必须先确定价格区、成交量区，再为时间刻度、方向图例以及桌面端可见的“时间”轴标题计算底部安全区。

当桌面基础比例无法同时容纳可读成交量区与底部安全区时，组件必须增加实际像素高度，不得继续压缩成交量区，不得隐藏时间刻度或图例，也不得制造页面横向溢出。桌面空间充足时保持接近 `16:9`；移动端允许自然增高。不得由业务 CSS 再用固定比例覆盖组件计算结果。

ECharts 画布高度只覆盖价格、成交量和时间刻度；方向图例与桌面“时间”标题由组件外层稳定 DOM 承载。容器宽度不大于 `720px` 或使用 compact 变体时不渲染可见“时间”标题，也不得继续为它保留空白高度；横轴语义继续由时间刻度、图表 `aria-label` 和可访问摘要承担。组件计算出的总高度必须同步到外层实际高度，避免库内部自动布局改变业务几何。

桌面端纵轴标题继续垂直显示。容器宽度不大于 `720px` 时，ECharts 纵轴名称必须关闭，并在价格区和成交量区左上角分别渲染水平小标题；标题使用共享表面与文本令牌，不得挤占纵轴数字标签。左侧 gutter 必须根据价格与成交量实际格式化后的最长可见标签估算宽度，移动端不得继续固定保留桌面纵向标题的宽度。

## 7. 底部安全区

桌面端的时间刻度、方向图例和“时间”轴标题分别拥有独立安全区；移动端和 compact 变体只保留时间刻度与方向图例两层安全区：

- 时间刻度不得侵入成交量绘图区；
- 时间刻度与图例之间至少保留约 `8px`；
- 桌面端图例与“时间”轴标题之间至少保留约 `10px`；
- 桌面端“时间”轴标题与图表底边至少保留约 `6px`；移动端图例与图表底边保留同等底部安全边距；
- 两项图例按实际文字总宽度围绕绘图区中心整体居中，而不是围绕整个卡片或平均分配半栏。

安全区必须根据实际屏幕字号和最长 `HH:mm` 标签旋转后的真实占用动态计算。移动端取消可见“时间”标题后，释放的高度必须真实减少组件总高度，不能保留空占位。

## 8. 浏览器回归

必须在以下尺寸验证真实几何：

- `1684 × 931` 桌面端；
- `721 × 445` 共享边界刻度问题复现场景；
- `390 × 844` 移动端；
- `320 × 700` 极窄移动端；
- `390 × 844` 且根字号放大到 `125%`。

浏览器测试必须通过组件稳定 `data-*` 接口和实际边界同时验证：ECharts SVG 已初始化、full 成交量区实际高度、`22%` 最低占比、双 Grid 零间距、`1px` 分界线、整数动态纵轴刻度、动态横轴间隔、时间刻度不侵入成交量区、对应断点的两层或三层底部安全区、图例围绕绘图区中心居中以及页面无横向溢出。

共享边界回归必须读取实际 ECharts SVG 文字节点，确认价格最小刻度存在、成交量最大刻度不存在，并且价格轴左侧的共同边界区域只有一项可见纵轴刻度。只检查 Option 字符串或 `data-*` 声明不足以证明问题已修复。

`tests/browser/market-chart-readability.spec.ts` 必须在 `390 × 844` 实际页面中验证：约 `10～12` 的价格数据不会包含零点或扩展到无关大区间；成交量刻度数不少于 3 且存在非零中间刻度；价格色角色为 info 且与 success 色不同；移动水平分区标题存在、左侧 gutter 小于桌面旧固定值、可见“时间”标题不存在，并读取实际 ECharts SVG 非零成交量标签。

浏览器交互回归还必须分别在价格区和成交量区移动到同一横坐标，确认 Tooltip 内容一致、联动指针启用、Series emphasis 已禁用且页面无运行时错误。

Tooltip 持久性回归必须让父组件至少每秒发生一次无关重渲染，鼠标静止超过正式 `5s` 轮询周期并等待至少 `6.5s`，随后再触发一次真实行情 Option 更新；两阶段 Tooltip 均须保持可见、ECharts 实例 ID 不变，真实更新后内容须刷新。最后必须验证指针离开图表时 Tooltip 正常隐藏。

`tests/browser/mobile-chart-tap-highlight.spec.ts` 必须在 `390 × 844`、`hasTouch: true` 和 `isMobile: true` 的 Chromium 上下文中，读取行情图外层、共享图表根、画布宿主、实际 SVG 与路径节点的计算样式，确认 `-webkit-tap-highlight-color` 全部透明，并执行一次真实 `tap()`；只检查 CSS 源码字符串不足以证明动态 ECharts 子节点已被覆盖。

## 9. 防回退

不得：

- 恢复“窄屏优先压缩成交量绘图区”；
- 让 full 成交量图区低于 `68px`、compact 低于 `48px`，或低于数据绘图区的 `22%`；
- 让 full 成交量轴退回两个刻度并在隐藏最大刻度后只剩 `0`，或删除非零柱 `2px` 最小可见高度；
- 恢复价格区与成交量区之间的空白间距，或删除共同边界的 `1px` 分界线；
- 在共享边界同时显示价格最小刻度和成交量最大刻度，或把标签所有权改给成交量轴；
- 为凑固定刻度数无理由把窄幅价格数据扩展到零点或远离真实数据的范围；
- 让价格折线重新使用净主动买入成功色，或让主要轴刻度和图例退回 muted 低对比度文字；
- 把上下 Grid 恢复为分别触发 Tooltip、分别选取分段或不同步的 AxisPointer；
- 让 AxisPointer 或 Series emphasis 改变、模糊或隐藏价格折线；
- 让普通轮询、无关重渲染或真实行情 Option 更新在鼠标静止时清除 Tooltip，或用 `alwaysShowContent`／超长 `hideDelay` 规避正常交互生命周期；
- 恢复固定 12 个两小时横轴分段、固定 3／5 个价格刻度或固定 2／3 个成交量刻度；
- 用固定 `16:9` 最终覆盖动态比例；
- 在底部空间不足时隐藏时间刻度或图例；移动端不得恢复冗余可见“时间”标题及其空占位；
- 在移动端继续使用桌面纵向轴标题和固定大左边距，或让水平分区标题覆盖刻度和数据；
- 让成交量刻度重叠、柱越出成交量区或侵入价格区；
- 让时间刻度、图例和轴标题互相覆盖或越出图表；
- 使用负外边距、缩小到低于 `--font-size-xs` 或删除图例规避几何问题；
- 只覆盖按钮或链接的 tap highlight，而遗漏 `.economy-chart`、`.economy-chart__canvas` 的动态子节点或 `.market-history-chart` 指针交互外层；
- 绕过 `EconomyChart` 直接初始化 ECharts，或用 ECharts 私有 DOM 作为测试合同。
