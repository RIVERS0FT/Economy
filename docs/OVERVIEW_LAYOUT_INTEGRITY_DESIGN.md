# Economy 概览布局完整性设计

> 状态：当前正式概览布局防回退基线  
> 适用项目：`RIVERS0FT/Economy`  
> 更新时间：2026-07-25

## 1. 目标

概览页必须在桌面、紧凑桌面和平板宽度下保持完整的经营决策层级；签到日历、经营提醒、资产变化和挂单不得因侧栏、标题压缩或短列表滚动而降低可读性。

## 2. 外层轨道唯一性

```text
第一排：今日经营 + 本周签到
第二排：生产摘要 + 资产构成 + 当前挂单
```

`.home-grid` 始终只有一个外层轨道，内部两排各自负责分栏。不得让历史全局三列样式成为概览最终计算值。

## 3. 实际内容宽度响应式

- 大于 `1050px`：第一排按 `5:7` 两列，第二排三等列；
- 不大于 `1050px`：第一排单列，第二排两列，当前挂单跨两列，卡片恢复自然高度；
- 不大于 `580px`：两排全部单列；
- 侧栏展开或折叠跨过断点时必须立即重新排版。

宽布局下今日经营宽度大于 `420px`，签到卡宽度大于 `560px` 且宽于今日经营；三张摘要卡最窄宽度大于 `280px`。

## 4. 高度和内部滚动

大内容宽度使用约 `370px` 的第一排和约 `330px` 的第二排。经营提醒和最多三条真实现金事件不得内部滚动；当前挂单只有超过三条时使用 `overview-open-orders-list--scrollable`。

## 5. 签到日历

签到卡必须展示周一至周日七个日期格，并同时表达：

- 已签到：成功状态与“已签”；
- 今日未签到：强调轮廓与“今日”；
- 已经过期未签到：虚线或弱化状态与“漏签”；
- 未来日期：弱化状态与“未到”。

日期格的判断只比较服务器返回的 `todayKey`、`dateKeys` 和 `claimedDateKeys`，不得读取浏览器墙上时间。桌面七格同排；`390×844` 下仍保持七列紧凑布局，完整星期文字、日期和状态不得隐藏或缩写。

签到按钮是卡片唯一写操作。今日已签到时禁用并显示“今日已签到”；第七次签到将完成全勤时显示“签到领取 1 + 5 宝石”。注册所在不完整周必须显示“下周起参与全勤”。

## 6. 本周现金变化

“本周资金变化”只展示最近七天且 `cashDelta !== 0` 的本地现金事件。服务器状态同步、纯库存变化和估值刷新不得进入列表；辅助说明固定为“当前设备现金记录”。

## 7. 状态栏趋势表达

总资产周变化只能使用一次方向表达：上升 `↑`、下降 `↓`、无变化 `→`。可见数值使用绝对值，不得同时显示下降箭头和负号。

## 8. 浏览器运行时回归测试

Playwright 至少覆盖：

1. `1684×931` 下第一排两卡和第二排三卡占满内容区；
2. `1440×900` 下第二排标题与核心指标进入首屏；
3. `900×1000` 下第一排单列、第二排两列；
4. 侧栏折叠后根据实际内容宽度恢复两列和三列；
5. 签到日历七格不重叠、不横向溢出，并验证已签、今日、漏签、未来、全勤和注册周状态；
6. 零现金同步事件不显示，一至三条现金事件不滚动；
7. 一至三条挂单不滚动，超过三条时启用内部滚动；
8. 所有概览核心容器 `scrollWidth` 不得大于 `clientWidth`。

测试必须比较真实 `getBoundingClientRect()`、计算后的网格轨道和滚动尺寸，不能只检查源码字符串。

## 9. 文件职责

- `src/styles/overview.css`：概览两排、签到日历和容器查询；
- `src/styles/overview-polish.css`：固定高度、短列表滚动和辅助文字；
- `src/pages/OverviewPage.tsx`：签到日历状态、经营提醒、现金筛选和挂单滚动；
- `tests/browser/runtime.spec.ts`：真实浏览器几何和签到语义回归；
- `scripts/verify-overview-content.mjs`：防止签到卡、布局和服务器日期规则被静默移除。
